# Погода и климат

Учебное многокомпонентное приложение на основе готового сайта «Погода и климат». Проект разделён на четыре сервиса и запускается через Docker Compose.

## Архитектура

- **frontend** — HTML, CSS и JavaScript; Nginx отдаёт статические файлы и проксирует `/api/` в backend.
- **backend** — PHP API, бизнес-логика, история запросов и работа с MySQL.
- **db** — MySQL 8.4; таблица создаётся при первом старте из `db/init.sql`, данные сохраняются в volume.
- **web-service** — внутренний Python/Flask-адаптер, обращающийся к wttr.in.

## Запуск

1. Установите Docker Desktop (Windows/macOS) или Docker Engine с Docker Compose.
2. В корне проекта скопируйте `.env.example` в `.env` и задайте собственные пароли.
3. Выполните:

   ```bash
   docker compose up --build -d
   ```

4. Откройте <http://localhost:8080>.
5. Просмотр логов: `docker compose logs -f`.
6. Остановка: `docker compose down`. Чтобы также удалить сохранённую историю: `docker compose down -v`.

## Примечания

- Для получения погоды контейнеру `web-service` нужен исходящий HTTPS-доступ к `wttr.in`.
- Секреты хранятся в `.env`, этот файл исключён из Git. Не публикуйте реальные пароли.
- MySQL автоматически создаёт таблицу только при первом создании пустого тома данных.
- Проект использует мостовую сеть Docker Compose; внутренние сервисы доступны друг другу по именам `backend`, `db` и `web-service`.
